## 🔧 Ready to Run

### To Test the App:
```bash
# Navigate to project
cd "innate apps/RepEnhanceApp"

# Start Metro bundler
npx react-native start

# In another terminal, run on iOS simulator
npx react-native run-ios
```

### To Run on Physical Device:
1. Open Xcode
2. Open the ios/RepEnhanceApp.xcworkspace file
3. Select your device
4. Build and run
